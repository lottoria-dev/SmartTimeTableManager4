Smart Timetable Manager 4
개발: MathTime

한국 학교의 수업 교체·보강 전용 프로그램입니다.
큰 시간표에서 클릭·드래그로 수업을 옮기거나 자동 교체안을 검토합니다.

시작
1. 배포 ZIP을 새 폴더에 압축 해제.
2. TimeTableManager.exe 실행.
3. templates의 동일셀·분리셀 Excel 중 하나를 학교 자료로 편집.
4. 파일 → 시간표 파일 열기. 작업은 .ttm으로 저장.

주요 기능
- 조회 / 맞교환 / 보강 / 수동 교체 / AI 자동.
- 수업 잠금·학년 행사 제외·변경 다이어그램·월별 결보강 통계.
- 도움말 → 학교 상황별 활용 / 버전 히스토리.

templates
- 동일셀: 한 셀에 교과명과 교사명을 줄바꿈으로 입력.
- 분리셀: 교과 행 아래에 교사 행. 아래 행 학년·반은 공란.
- 예제 교사명은 모두 가상 이름. CSV와 편집 안내도 포함.

사용 조건
교육기관 교직원의 학급 운영·업무 목적 무료 사용.
상업적 영리 목적 사용 금지. 자세한 조건은 LICENSE.txt 참조.
외부 구성요소 고지는 THIRD_PARTY_NOTICES.md 및 third-party-licenses 참조.

본 프로그램은 일부 코드 작성·검토 및 문서화에 생성형 AI를 활용했습니다.
자동 교체는 PC 안에서 탐색하며 외부 AI API에 시간표를 전송하지 않습니다.

배포 ZIP과 함께 제공되는 .sha256.txt 또는 SHA256SUMS.txt로 해시 확인.
버전별 변경 내역: VERSION_HISTORY.txt.
