Smart Timetable Manager 4 · 4.0.3

실행
1. 새 폴더에 ZIP 압축 해제 → TimeTableManager.sln 열기.
2. Visual Studio의 .NET 데스크톱 개발 환경, .NET 10 사용.
3. TimeTableManager.App 시작 프로젝트 지정 → NuGet 복원 → Ctrl+Shift+B → F5.
4. 제목과 프로그램 정보에서 4.0.3 확인.

실행 ZIP 생성(사용자 PC)
1. App 프로젝트 → 게시 → Standalone-win-x64 또는 publish-standalone.cmd 실행.
2. PowerShell에서: powershell -NoProfile -ExecutionPolicy Bypass -File tools\Package-Release.ps1
3. artifacts\release의 SmartTimeTableManager4-4.0.3-win-x64.zip과 SHA256SUMS.txt 확인.
4. 압축을 다른 폴더에 풀고 실행. docs\RELEASE_CHECKS.txt 확인 후 GitHub에 업로드.

템플릿·버전 히스토리
1. templates의 두 XLSX를 각각 새 작업으로 열기. 양쪽 모두 17학급·37교사·1주544수업 확인.
2. 분리셀은 교과 행 아래 교사 행. 아래 행 학년·반은 공란.
3. 도움말 → 버전 히스토리에서 4.0.3~4.0.0 확인.
4. Package-Release.ps1 실행 결과 ZIP에 templates와 VERSION_HISTORY.txt 포함 확인.

AI 교사별 허용
1. AI 자동 → 시작 수업·목적 교시 선택 → 자동 교체안 찾기.
2. 확인창에서 교사별 추가 수업 이동 허용을 선택. 재변경 수업은 표시됨.
3. 직접 선택한 수업도 이미 변경했다면 재변경 허용 체크. 원하지 않으면 취소.
4. 3연강 이상은 교사별로 허용. 체크를 끄면 해당 연강을 회피하며 재탐색.
5. 일부 미허용: 선택 반영·대체안 찾기 → 새 안을 다시 확인. 전체 허용: 교체안 보기 → 변경 적용.
6. 목적 교시는 유지. 거부 조건 때문에 실패하면 목적·범위를 바꾸거나 새 탐색을 시작.
7. 거부는 임시 조건. 새 탐색에서는 초기화하며 실제 수업 잠금·시간표는 바꾸지 않음.
