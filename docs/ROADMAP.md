# 4.x 개발·관리

4.0.0: 수업 교체·보강 중심의 첫 정식 소스. 조회·맞교환·보강·수동·자동 모드, 월 관리·통계와 학교 상황별 도움말.

4.0.1: 우클릭·하위 메뉴 빈 아이콘 영역 제거, 체크 표시 유지. 소스 정적 점검; Windows 화면 확인 대기.

4.0.2: AI 교사별 이동·재변경·연강 허용, 거부 조건 유지 재탐색. 회귀 사례 추가; 실행 대기.

4.0.3: 버전 히스토리·익명 동일셀/분리셀 템플릿·배포 안내. Windows에서 가져오기 확인 대기.

4.0.x: Windows에서 확인된 오류·가독성 수정. 새 태그는 4.0.1처럼 작성.
4.1.x: 학교 사용 의견에 따른 기능 개선. 지정 시간·잠금·월 통계·이력 호환성을 먼저 검토.

변경마다 필요한 범위만 검증. 화면 표시·실행 속도·EXE는 Windows 확인 후 결과 기록. 정적 점검을 실제 실행 통과로 기록하지 않음.
