두 양식 중 하나만 선택해 편집합니다. 두 파일의 예제 수업은 같습니다.
교사명은 모두 가상교사01 등의 가상 이름입니다. 학교의 실제 과목·교사명으로 바꾸세요.

동일셀.xlsx
- 셀 첫 줄: 교과명 / 둘째 줄: 교사명.
- Excel에서 Alt+Enter로 줄바꿈. 교과와 교사는 한 셀에 입력.

분리셀.xlsx
- 학급마다 두 행. 위: 교과명 / 아래: 교사명.
- 아래 교사 행의 학년·반은 비워 둠. 수업 칸을 세로 병합하지 않음.

공통
- 상단 요일·교시 두 행과 학년·반 열 유지. 월~금 사용.
- 학급을 추가할 때 같은 행 구조로 추가.
- 수업을 지울 때 교과명·교사명을 함께 삭제.
- 같은 교사는 모든 칸에서 같은 이름 사용. 동명이인은 이름 뒤에 구분 글자 추가.
- 수식 대신 값으로 저장. 일반 XLSX 파일 사용.
- 파일 → 시간표 파일 열기 → XLSX 선택.
- 월 관리·2주 반복은 프로그램에서 설정. 템플릿은 1주 기초 시간표.
- 작업을 시작한 뒤에는 .ttm으로 저장. Excel·CSV는 기초 자료용.

CSV도 함께 제공
- UTF-8로 저장된 동일셀·분리셀 예제.
- Excel·스프레드시트의 가져오기 기능에서 텍스트 형식으로 열고 XLSX로 저장 권장.
- 직접 CSV를 열면 한글·자동 날짜 변환·셀 줄바꿈 표시를 확인.

두 양식 확인
- 각각 새 작업으로 열면 17개 학급, 37명 교사, 1주 544개 수업.
- 2주 반복을 선택하면 수업 수가 두 배가 됨.
- 이름을 바꾸기 전 예제 그대로 열어 두 양식의 결과를 비교 가능.
