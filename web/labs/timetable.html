Smart Timetable Manager 4

큰 시간표에서 수업을 확인하고, 교체·보강을 편하게 처리하는 한국 학교용 프로그램입니다.

4.0.3 실행 ZIP 다운로드 릴리즈·해시 확인 버전 히스토리 소스 코드

Windows x64 · 자체 포함 실행 ZIP · 교육기관 교직원 업무 목적 무료 사용

처음 사용하기

  1. 실행 ZIP 압축 해제 → TimeTableManager.exe 실행.
  2. 파일 → 시간표 파일 열기. Excel·CSV는 기초 시간표, .ttm은 저장한 작업.
  3. 관리 월·편집 허용 시작일 확인 → 모드 선택 → 변경 적용 → 저장.

학급·교사 전체 CSV 및 교과명·교사명 동일셀/분리셀 Excel 양식을 사용합니다. 기본 조회는 오늘부터 다음 주 금요일까지입니다.

학교용 기본 템플릿

동일셀

한 셀에 교과명과 교사명을 줄바꿈으로 입력합니다.

분리셀

교과 행 바로 아래에 교사 행. 아래 행의 학년·반은 비워 둡니다.

두 양식 모두 지원합니다. 같은 예제 수업이며 교사명은 모두 가상 이름입니다. 학교 자료로 바꾸어 XLSX로 저장하세요.

Excel 템플릿 두 가지 다운로드

실행 ZIP의 templates 폴더에도 동봉합니다. UTF-8 CSV와 간단한 편집 안내 포함.

상황에 맞는 다섯 모드

조회

전체 시간표·변동 색상 확인. 셀을 누르면 같은 교사의 수업을 강조합니다.

맞교환

가능한 수업을 음영으로 확인하고 두 수업을 1대1로 교환합니다.

보강

공강 교사 또는 교장·교감 특별 보강을 배정합니다. 원래·새 담당을 확인합니다.

수동 교체

카드를 밀어내듯 순서대로 배치합니다. 진한 초록은 추천, 연한 초록은 배치 가능입니다.

AI 자동

시작 수업과 목적 시간을 지정합니다. 당일 우선으로 찾고 필요하면 이전·이후 날짜로 넓힙니다.

월 관리·변경 확인

변경 다이어그램과 결보강 통계. 잠금·학년 행사 제외·재변경 확인을 함께 제공합니다.

학교에서 이렇게 사용합니다

지각·회의로 1교시를 6교시로 옮겨야 할 때
  • AI 자동 → 시작 수업 → 6교시 목적 칸 → 교체안 찾기.
  • 당일 안이 없으면 이전·이후 날짜 범위를 확대합니다.
  • 지정한 목적 시간과 함께 바뀌는 수업을 확인하고 적용합니다.
갑작스러운 결근으로 보강이 필요할 때
  • 보강 → 수업 선택 → 공강 교사 선택.
  • * 표시 교사의 연강을 확인합니다. 교장·교감 특별 보강도 선택할 수 있습니다.
출장으로 하루 또는 오전 수업을 비워야 할 때
  • 수업 우클릭 → 교사 하루 수업 이동 → 하루 모두 / 오전만 다른 날짜로.
  • 배치를 우선한 뒤 연강 교사·교시·교과를 확인합니다.
  • 적용 후 수작업 확인 목록을 보며 필요한 수업만 조정합니다.
AI 배치 후 다른 교사의 시간이 맞지 않을 때
  • AI 교체안을 확인·적용한 뒤 수동 교체로 해당 수업을 선택합니다.
  • 재변경을 확인하고 새 시간에 배치합니다. 밀려난 카드도 순서대로 배치합니다.
  • 모든 카드 배치 후 적용·저장합니다.
학년 행사 또는 다른 요일 일과를 운영할 때
  • 행사: 날짜 제목 우클릭 → 해당 학년 제외.
  • 일과 변경: 날짜 제목 우클릭 → 기초 요일 적용 → 가져올 요일 선택.
  • 기초 요일 적용은 학교 계획으로 관리하며 교체 이력·변동 색상에서 제외합니다.
하루·오전 비우기는 배치 우선 → 연강 확인 → 필요한 수업만 수작업 조정입니다. 3·4연강 이상이 포함될 수 있으므로 적용 전 확인하세요.

저장과 통계

  • .ttm은 작업 보존, Excel·CSV는 배정 결과 전달에 사용합니다.
  • 월 경계 이동은 양쪽 월 통계를 확인합니다. 다음 월은 최신 작업 파일에서 관리 월을 변경합니다.
  • 월 통계는 기초 배정과 현재 배정의 최종 차이입니다. 실제 실시·미실시 기록과는 별개입니다.
  • 기초 요일 적용은 Ctrl+Z 대상이 아닙니다. 바꾸려면 기초 요일을 다시 적용합니다.
